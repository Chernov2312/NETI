# Доработки каталога NETI

## P0 — страницы и маршруты

- [x] Добавлена детальная страница проекта с ответом 404 для неизвестного UUID.
- [x] Профиль использует поля `user.User` и действующие маршруты.
- [x] Навигация учитывает состояние входа и ведёт в «Мои проекты».

## P1 — сценарии каталога и запуск

- [x] Авторизованный пользователь может создать проект с документом, тегами
  и изображениями. Владелец назначается из текущей сессии.
- [x] В «Моих проектах» отображаются собственные проекты. Редактирование
  и удаление доступны владельцу и модератору.
- [x] Авторизованный пользователь может выставить и изменить оценку от 1 до 10.
  На странице проекта отображается средняя оценка.
- [x] Для проектов без главного изображения отображается заглушка.
- [x] Выход завершает сессию через POST с проверкой CSRF.
- [x] PostgreSQL используется по умолчанию локально и в Docker.
  Настройки берутся из окружения, перенос данных из SQLite описан в README.
- [x] Локальный запуск и Compose используют общие настройки ключа, DEBUG,
  хостов и каталога медиа на хосте.

## P2 — валидация и проверка

- [x] Добавлены тесты регистрации, входа по логину и email, прав доступа,
  профиля, каталога, загрузок и оценок. Запуск из корня обнаруживает весь набор.
- [x] Форма проверяет тип и размер документов и изображений. Тесты покрывают
  отклонение недопустимых файлов.
- [x] Добавлены выбор и фильтрация тегов, редактирование галереи
  и проверка прав модератора.
- [x] В GitHub Actions настроены проверки Django и E2E на PostgreSQL, проверка
  production-контейнера и публикация образа в GHCR при push в `master`.

## Проверки после доработок

Настройте окружение по README и выполните команды из корня репозитория.

```powershell
python neti\manage.py check
python neti\manage.py makemigrations --check --dry-run
python neti\manage.py test
```
